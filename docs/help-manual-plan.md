# 遊び方説明（ユーザーマニュアル）計画

- 作成日: 2026-09-24
- 対象: `web/` のみ
- 決定事項（ユーザー選択）: 1 枚に全部 / 基本 3 項目だけ小アニメ・残りはアイコン + 1 行 / ヘルプボタンは右下ボタン群の一番上 / 初回の爆発後に「?」を一度光らせる
- 言語: 日本語と英語。ブラウザの言語設定で自動選択、トグルで切り替え（ユーザー選択: 画面上の文字すべてが対象 / トグルはタイトル画面と説明カード内）

## 1. 入口（2 か所）

| 入口 | 位置・見た目 | 注意点 |
|---|---|---|
| タイトルの "How to Play" | 導入画面の注意書きの下。小さな枠線付きの文字ボタン | 導入画面は押した瞬間にゲームが始まる作り。このボタンの pointerdown は伝播を止め、説明を読んでからタップで開始できるようにする |
| ゲーム中の「?」 | 右下ボタン群（声で溜める・言葉を書いて、壊す）の一番上に右寄せ。見た目は直径 32px の薄い円、押せる範囲は 44px | 溜め〜着弾の間はボタン群ごと薄くする（視界の邪魔をしない）。キーボードは `?` でも開く |

## 2. 説明の中身（1 枚・スクロール無し）

各行は全角 22 字以内（390px 幅で 1 行に収める）。

```
遊び方                                         ×
基本
 [アニメ] 長押しで溜める ─ 長いほど強い
 [アニメ] 離すと爆発 ─ 一瞬の静寂のあとに
 [アニメ] 短くタップ ─ 音が鳴り、光の種が残る
もっと遊ぶ
 ◇ 金の輪が光る瞬間に離す → クリティカル
 ◇ 満タンのまま押し続ける → 暴発
 ◇ 離す瞬間に弾く → その方向へ飛ぶ
 ◇ 爆発で種を巻き込む → 連鎖して旋律に
 ◇ 強い解放 7 回（画面下の点）→ 大団円
右下のボタン・スマホ
 ◇ 言葉を書いて、壊す ─ 言葉を粒子にして砕く
 ◇ 声で溜める ─ 叫んで溜め、黙ると爆発
 ◇ 溜めながらスマホを振る → 解放
音が鳴ります ・ 入力した言葉と声は送信・保存しません
```

- 小アニメ（基本 3 項目・約 56×40px のインライン SVG + CSS アニメ、2〜3 秒ループ）
  1. 溜める: 周りの光の点が中心へ集まり、進行の輪が満ちる
  2. 爆発: 中心が白く光り、輪が広がって点が飛び散る
  3. タップ: 波紋が出て、小さな星が残って瞬く
- 「もっと遊ぶ」以下の ◇ は、作品の粒子と同じシアン〜マゼンタの小さな線画アイコン（自作 SVG）
- `prefers-reduced-motion` では小アニメを止めて完成状態の 1 枚絵を見せる

## 3. 見た目とレイアウト

- 作品の上に重なる暗いガラス調のカード（ネオンの細い縁、背後はぼかして暗くする）。作品は背後で動き続ける
- 縦長（スマホ縦）: 1 列。横長で高さが低い画面（スマホ横・高さ 500px 未満）: 2 列（左に基本 + 右下のボタン、右にもっと遊ぶ）
- 高さが足りない画面では文字とアニメの大きさを一段小さくする。それでも溢れる極小画面だけ、カード内のスクロールを許す（切り取らない）
- 閉じ方: 右上の ×、背景のタップ、Esc。閉じたら開く前のボタンへフォーカスを戻す

## 4. 初回の案内

- 最初の爆発（初めての decay 突入）の後に、「?」を約 4 秒脈打たせる（3 回）
- 一度案内したら端末に「案内済み」だけを記録（localStorage。読めない環境では毎回案内しても害はない）。タイトルで説明を開いた人には案内しない

## 5. 日英対応

- 自動選択: 端末に記憶した選択があればそれ、無ければ `navigator.languages` に `ja` で始まるものがあれば日本語、それ以外は英語
- トグル: 「日本語 | EN」の小さな切り替え。タイトル画面の右上（押してもゲームは始まらない）と、説明カードの見出しの横（× の隣）。選んだ言語は端末に記憶（localStorage。読めない環境では毎回自動選択）
- 切り替えは即時・再読み込みなし。`<html lang>`、`document.title`、`meta description` も追従
- 対象の文字: タイトル画面（キャッチ・注意書き・How to Play）、右下のボタン（声で溜める・言葉を書いて、壊す）とマイクの状態表示 4 種、入力欄の案内文と iOS の入力ダイアログの文、「?」の読み上げ名、説明カード全体、場面が変わるときの一文 4 種、ページタイトル
- 対象外: 連鎖表示の "CHAIN"（元から英語）、`?debug` の診断表示（開発用）
- OGP（SNS 共有時の表示）は言語で切り替えられない静的な情報なので、日英併記にする
- 実装: `src/i18n.ts`（新規）に日英の辞書と `t(key)`・言語の検出と保存・切り替え通知を置く。HTML の固定文字は `data-i18n` 属性で辞書のキーを指し、切り替え時に一括で差し替える。動的な文字（マイクの状態・場面の一文・入力ダイアログ）は表示のたびに `t()` で引く
- HTML の初期文字は日本語のまま（スクリプトが動かない環境でも読める）。英語の人には読み込み直後に英語へ差し替わる

英語版の説明カード（案。1 行 40 字前後。390px 幅で折り返しても 1 枚に収まるかを検証で確認）:

## 6. 実装（ファイル単位）

| ファイル | 変更 |
|---|---|
| `index.html` | タイトルに "How to Play" ボタン、右下ボタン群の先頭に「?」、`<dialog id="manual">` と説明の中身 |
| `style.css` | 入口ボタン・カード・2 列レイアウト・高さ別の縮小・小アニメ・reduced-motion |
| `src/manual.ts`（新規） | 開閉、フォーカスの戻し、`?` キー、初回案内（localStorage）。main.ts は 1,600 行超のため分ける |
| `src/i18n.ts`（新規） | 日英の辞書、言語の検出・保存・切り替え、`data-i18n` の一括差し替え |
| `src/scenes.ts` / `src/main.ts` | 場面の一文・ボタンの状態表示・入力ダイアログの文を辞書のキー経由に |
| `src/main.ts` | 導入画面ボタンの伝播停止、状態に応じたボタン群の減光（body のクラス切り替え）、初回の爆発で案内を呼ぶ、説明を開いている間は `d` キー等のショートカットを無効化 |

ダイアログはネイティブの `<dialog>` + `showModal()`（Esc・フォーカスの閉じ込め・背景が標準で揃う。iOS Safari 15.4+）。

## 7. 検証（完了条件）

- 5 つの画面サイズ × 日英 2 言語 = 10 通りで説明が 1 枚に収まる（カードの `scrollHeight <= clientHeight`）: 1440×900 / 390×844（iPhone 縦）/ 844×390（iPhone 横）/ 375×667（iPhone SE）/ 768×1024（iPad）。各スクリーンショットを目視
- 言語の自動選択: ブラウザの言語を英語・日本語に差し替えて起動し、それぞれの言語で表示される。トグルで切り替えると画面上の文字がすべて変わり、再読み込み後も選択が保たれる。英語表示のまま遊んで、日本語の文字が画面に出ない（場面の一文・マイク表示・入力ダイアログを含む）
- タイトルの "How to Play" を押してもゲームが始まらない（導入画面が残り、AudioContext が作られない）。閉じてからタップで通常どおり開始
- ゲーム中の「?」で開く・Esc / × / 背景タップで閉じる・`?` キーで開く・開いている間はキャンバス操作が起きない
- 初回の爆発後に「?」が一度だけ脈打ち、再読み込み後は脈打たない
- `pnpm build` 通過、コンソールエラー 0
- 本番デプロイは実装と確認のあと、ユーザー確認を取ってから
